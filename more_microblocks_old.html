Connecting with USB

Use a direct USB connection when your platform supports it.

Make sure the USB cable is a data cable and not only a power cable.
  1. Connect the Springbot to your computer with a USB data cable.
  2. Click Connect.
  3. Select the USB Port where the Springbot is connected.

Connecting with BLE

BLE is available in the browser version and on iPad.

When connecting over BLE, select the device with the same 3 letters shown on the Springbot when it is first powered up.
  1. Power up the Springbot.
  2. Note the 3-letter identifier shown on the device.
  3. Open a BLE-capable platform of MicroBlocks.
  4. Select the matching device from the BLE list.
If several devices are visible, use the 3-letter code on the Springbot to make sure you choose the right one.
