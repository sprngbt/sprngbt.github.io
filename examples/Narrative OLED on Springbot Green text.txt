When connecting the OLED to the Springbot Green, you need to add a library and initialise the display.When connecting the OLED to the Springbot Green, add the "OLED Graphics" library first. Follow this sequence: Add Library>Libraries>Graphics and Displays>OLED Graphics.We use the “Forever” command to have it running continuously.The MicroBlocks program reads the air temperature data from the sensor on the Springbot, and writes the label, data, and units to the OLED screen.In the loop we clear the screen before repeating the actions so that the data output on the display refreshes each time.
