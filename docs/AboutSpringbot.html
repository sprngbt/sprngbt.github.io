About Springbot Utility

Springbot Utility is a companion application for configuring and commissioning Springbot devices. A Springbot is a small controller built around the Espressif ESP32‑S2 microcontroller with an attached I²C NFC tag (STMicroelectronics’ ST25DV). Springbots sense environmental conditions and post telemetry data to an MQTT broker where you can explore it in Kibana/Elasticsearch dashboards.

The Springbot reads its configuration from its NFC tag on start‑up. Writing that configuration manually or through WiFiManager can be error‑prone and time consuming. Springbot Utility uses Apple’s Core NFC framework to communicate with the ST25DV tag. It writes configuration records and returns the tag’s unique identifier, all with a simple tap.

Key Features

  • Format a Springbot tag: Prepare the ST25DV tag for use and optionally turn on the Springbot’s LED. Formatting wipes any previous contents and writes a known structure to the tag.
  • Configure Wi‑Fi credentials: Specify the Wi‑Fi SSID and password that the Springbot should use. The app packages these values into a Wi‑Fi Simple Configuration token and writes it to the tag. You can also assign a friendly name (e.g. Unit #12) and the app will increment the number automatically for subsequent devices.
  • Copy device identifiers: After formatting or writing, the app displays the Springbot’s UID (8‑byte hex string) and allows you to copy it to the clipboard for record‑keeping or dashboard mapping.
  • Optional Shortcuts integration: When enabled, the app triggers your custom “Springbot” iOS Shortcut after successfully writing Wi‑Fi credentials. The shortcut receives the device UID and name in one string, so it can register the Springbot with your MQTT broker, update a Kibana index or perform any additional automation you’ve defined. Launching Shortcuts uses shortcuts:// URLs and does not require special entitlements.
  • Setup page: Save default SSID, password and organisation values using @AppStorage, so you don’t have to enter them each time.
  • Information section: Access this page, view the privacy policy and end‑user licence agreement, send feedback via email or rate the app on the App Store.

Privacy & Data Use

Springbot Utility does not collect personal data or track you. It only reads from and writes to the attached NFC tag. The configuration values you enter are stored on your device using persistent storage and transmitted to the Springbot over NFC. When you use the Mail or App Store links, those interactions are handled by Apple’s own applications.

This app is built by the Springbot community to make setting up ESP32‑S2 based devices straightforward. By using NFC instead of captive portals or recompiling code, you can commission multiple Springbots quickly and reliably.
